## AIFW 与 Offscreen 退役

删除 `aifw/`、`offscreen.js`、`offscreen.html`，合计 **4,213,067 字节**。移除 `offscreen` 权限和 `wasm-unsafe-eval`，扩展页 CSP 为 `script-src 'self'; object-src 'self'`。

切断五个主脚本中的初始化、文本脱敏、结果还原、本地客户端与自定义 HTTP 脱敏调用链；进阶设置不再显示 AIFW 说明、外链或服务器配置。配置合并时将 `sensitiveConfig` 收敛为关闭状态，并清除嵌套及点号形式的旧覆盖项。

翻译文本直接交给当前选择的服务。Edge 测试用旧配置 `sensitiveMode: inner` 启动，确认邮箱和电话号码原样出现在实际后台发往本机测试 API 的请求中；运行期间 Offscreen Document 数为 **0**。

## CSS、HTML 与内嵌资源

删除五个未使用的外部样式：`epub.css`、`input.css`、`hero.css`、`store.css`、`assistant.css`。清除设置页失效引用及侧栏不存在的 `favicon.ico`、`side-panel.css`、`reward-center.css` 链接，加载圈默认色改为朱色。

设置页的 `pico.css`、`options.css` 及弹窗必要样式继续通过 HTML 加载。脚本中的 CSS 注册表同时服务于 Shadow DOM，注册表声明不代表已注入当前文档。本轮删除设置脚本中无消费者的 `pico.css`、`options.css`、`hero.css` 内嵌副本，保留输入框、页面内弹窗和侧栏使用的样式。视觉验收与导航布局计算值检查均通过。

按宣传横幅与订阅弹窗的所属节点定位，清除三个脚本中的 **9 份 Base64 营销图片**。服务图标和有效界面资产保留。

## 快捷键与词条

| 命令 | 默认快捷键 |
|---|---|
| 翻译 / 还原网页 `toggleTranslatePage` | Alt+A |
| 双语 / 仅译文 `toggleOnlyTranslation` | 用户设置 |
| 文本侧栏 `toggleSidePanel` | Alt+S |
| 输入框翻译 `translateInputBox` | Alt+I |
| 悬停翻译开关 `toggleMouseHoverTranslateDirectly` | 用户设置 |

浏览器命令修正原拼写错误；后台映射兼容内部 `toggleOnlyTransation` 协议与原配置。Edge 自带的 `_execute_action` 工具栏动作不计入五项自定义命令。

`en`、`zh-CN`、`zh-TW`、`zh-HK` 分别删除 432 个已退役功能词条，涉及文件、图片、写作、会员运营、奖励中心、云同步及脱敏设置。浏览器 `_locales` 仅保留 manifest 使用的描述。共享错误、服务与动态构造的文案仍然保留。
