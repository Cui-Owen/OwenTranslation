# 欧文翻译：原版依赖裁剪分析

日期：2026-10-23。对象：`1.34.3 + Owen 0.2 B`。状态：完成审计与方案；未修改扩展或构建脚本。

## 核心判断

下一版应收敛为：**网页双语翻译、现有字幕捕获与翻译、Magpie 分句、用户直连翻译服务、本地术语、本地设置**。原站账号、会员体系、官方中转、全站悬浮球、官方 WebApp 外跳、远程运营目录均可退出这条产品链。

当前 B 版已删除一批文件、图片、写作、活动和遥测入口，但仍继承了原产品的服务分发和账号结构。继续隐藏几个按钮收益有限；真正的收口对象是“身份 → 服务授权 → 云同步 → 商业错误提示”和“远程配置 → 服务目录/专家目录 → 页面入口”两条链。

主要证据：

| 当前发现 | 核对结果 | 处理结论 |
|---|---|---|
| 全站悬浮球 | PC/H5 主开关仍为 true，关闭的是引导；存在文本侧栏使用次数超过 2 后自动 pin 的逻辑 | 整套删除球，保留独立页面弹窗宿主 |
| 主按钮与本地文本功能割裂 | popup“文本翻译”打开原站；本地侧栏“放大”也打开原站 | 主按钮直达本地文本侧栏，放大改本地页或删除 |
| 设置入口分裂 | 浏览器“选项”进 Magpie 独立页；popup/侧栏齿轮进原设置页 | 一个本地设置页，Magpie 并入字幕设置 |
| 原站外链 | 品牌、帮助、更新日志、安全声明、在线对比、术语会员链接仍保留 | 品牌取消跳转；帮助/变更记录/数据说明本地化；其余删除 |
| 字幕网站链接 | 浏览器读取字幕设置页得到 235 个锚点，其中 220 个 HTTP 外链、214 个经过原站 `/leaving/` | 删除链接墙，或仅保留少量直接原网址；保留网站适配规则 |
| 原站账号之外的登录 | 导入/导出页仍显示 Google Drive 同步，包内存在 OAuth、token 校验、Drive 读写 | 连同云备份 UI 和 OAuth 整套删除；保留本地导入导出 |
| 自动联网依赖 | 仅打开界面时，观察到 5 个原厂域名的请求 | 配置、目录、图标和术语数据打包本地；删除原厂网络分支 |
| 图片/漫画残留 | 32 条请求改写规则中仍有 23 条图片/漫画域名规则 | 随已移除的图片能力直接清理 |
| 配置复杂度 | 服务表有 103 个原始键，含版本覆盖；网站规则有 800 条 | 服务改白名单；网站解析规则保留并冻结版本 |
| 语言资源 | `locales.json` 为 4,179,673 字节，含 22 组 locale | 中文为主，保留英文回退后裁剪语言包；实际节省以产物为准 |

## 2. 悬浮球：建议整套删除

网页翻译已有工具栏 popup、右键和快捷键，字幕已有播放器控件。全站球主要增加常驻遮挡、拖拽状态、长按菜单、提示计数和一套额外的侧栏入口，均非翻译引擎前置条件。

删除范围：

- PC/H5 球主组件、迷你模式、拖拽/吸附、touch/mouse 监听、关闭菜单。
- hover 延迟、侧边位置、透明度、禁用网站、安装日期门槛、提示次数和使用引导。
- 球上的设置/反馈/侧栏按钮、使用量触发的自动 pin。
- popup 的球开关、`#floating` 设置页、相关快捷消息、CSS 和存储偏好。
- 默认配置、用户 `.add`、版本 `.add_v`、远端覆盖中的球配置。最终 policy 在所有合并后强制关闭，再删除实现。

必须分开的三个对象：

| 对象 | 决策 | 原因 |
|---|---|---|
| 全站悬浮球 | 删除 | 重复入口，无引擎依赖 |
| 视频播放器内字幕按钮 | 保留 | 字幕开关、字幕设置的直接入口 |
| 划词翻译图标 | 独立保留，可默认关闭 | 按选区定位和触发，与球独立 |

`wH` 在球关闭时仍调用 `Nj` 创建页面内 popup 宿主；整段删除初始化链会连带破坏页面设置弹窗。应保留 `Nj`，移除球挂载分支。

代码证据：`surfaces/baseline/content_main.pretty.js:130958` 主初始化；`:113282` Nj；`:112617` 球组件；`:110895` 拖动/长按；`:113054` 偏好；`:36219` 默认与用户配置合并；`:36271,:36289` 自动 pin；`:124190,:124253` 播放器按钮；`:81359,:82715` 划词。现有 `scripts/policy.cjs:16` 只关球引导，未硬关球。

## 3. 登录：可以删除，必须先拆依赖

登录向官方服务、配置同步、术语云同步、字幕服务和商业提示供给身份。正确顺序是先替换这些消费者，再删身份链。

| 依赖层 | 删除范围 | 保留/替代 |
|---|---|---|
| 身份 | PKCE challenge/verifier、exchange token、session、原站 bridge、账号刷新/登出、头像/邮箱/订阅状态 | 本地设置和用户服务凭据 |
| 会员翻译 | Pro/Max 服务、官方 AI 中转、官方 token provisioning、试用和额度 | Direct/BYOK 服务及用户指定地址 |
| 官方免费服务 | free-model/get-token、Silicon/GLM token、AIGW free routes 等 | 真正直连的免费引擎或用户 Key |
| 配置云同步 | user/settings、自动同步、云端密钥加密开关、原账号同步按钮 | local storage、本地导入导出；浏览器 sync 可独立决定 |
| 术语云同步 | glossary-meta/config、上传/删除、云版本/云回滚、Pro/ownerId/apiOrigin 守卫 | 本地术语适配器、本地增删改、CSV、历史 |
| 商业提示 | 登录赠礼、续费/升级/额度弹窗、奖励中心、会员徽章 | 服务缺配置和网络错误的直接提示 |
| 账号地区选择 | 与原账号数据区和服务分发绑定的“国家地区切换” | 简繁体、界面语言、目标语言保持独立 |
| Google Drive | OAuth client/授权窗、缓存 token、校验/撤销、Drive 备份与恢复 | 本地文件备份 |

“免费”“Gemini”“OpenAI”等名字不能作为保留依据。同一个服务类同时实现直连与官方中转；部分免费模型也从原厂换 token。必须按实际 provider、group、endpoint 和 token 来源筛选。

术语是本轮最需要重构的连接点。本地 IndexedDB 与远端适配器共用协调器，直接删 getUserInfo 会让本地编辑撞上 login_required 或云写入守卫。替换为 local-only adapter，保留串行锁、dirty intent 恢复、本地历史、hash/CAS 和本地删除；迁移词条与待提交状态后停止远端重试。

已有配置若指向 Pro 服务，升级时迁移到保留服务；已有本地词条、API Key、快捷键和 Magpie 地址必须保留。此前“保留登录”的 B 版取舍服务于原官方引擎继续可用，不构成本次独立化的技术约束。

代码证据：`account/background.pretty.js:1514,25934,26036,26068,26135,34652,36663,45112`；`account/content_main.pretty.js:118453`；`account/options.pretty.js:60763,65425,65545,65604,66980,67095`。Google Drive 在未登录原站的干净浏览器中仍显示于导入/导出页，属于另一套登录。

## 4. 官方服务替换边界

| 能力 | 处理 | 必须保留的能力 |
|---|---|---|
| 官方 YouTube AI 分句 `subtitles/yt-asr-subs` | 删除请求、token、Pro 条件和官方语言白名单 | Magpie 与本地 sCe 分句；字幕时序、videoId 校验、旧请求丢弃 |
| 官方音频转写 `asr-audio/v2/*` | 删除任务创建/轮询、额度/试用 UI | 网站已有字幕的捕获与翻译 |
| 云语言检测 `api/predict/batch` | 删除 HTTP 分支和服务端强制兜底 | 本地检测模型、browser.i18n、中文规则、JS 投票与兜底 |
| AI 专家市场 | 删除远端目录、头像、推荐排序、贡献按钮 | 用户自定义提示词；将选定模板作为本地数据 |
| 在线术语目录 | 取消启动拉取，按需打包精选数据或只用用户词表 | 本地词表与按网页/语言匹配逻辑 |
| 原站连通性检测 | 删除 api2 connectivity_check | 由“测试连接”检查当前所选服务和 Magpie |

Magpie 处理已有字幕的分句，不执行原官方 ASR 的音频识别。删除 ASR 的实际产品结果是“使用网站已有字幕”，不是提供了一套新 ASR。

`telemetry:false` 只涉及相应遥测路径。语言检测存在 serverDetect 强制云兜底，不能据此推断检测文本从不出浏览器。

代码证据：`account/content_main.pretty.js:124881,125016,125059,125570,125643`；`account/background.pretty.js:16846,17178,20100`。

## 5. 自动联网与远程配置

干净 Edge 临时配置中，打开 popup、设置分区、文本侧栏和 Magpie 页，记录到以下请求。记录范围为请求发起，不将其视作响应成功或使用频率统计。

| 域名 | 观测路径/资源 | 建议 |
|---|---|---|
| config.immersivetranslate.com | default_config.json、tags-config.json、dynamic-i18n.json | 固化本地配置；删除标签运营和动态语言包同步 |
| api2.immersivetranslate.com | connectivity_check | 删除原站探活；只测试实际使用的服务 |
| ai.immersivetranslate.com | plugins/meta 与各专家 JSON | 删除在线市场；提示词本地化 |
| s.immersivetranslate.com | 专家头像、服务商图标、功能示意图等 | UI 需要的图标打包，其余删除 |
| assets.immersivetranslate.cn | static/terms/meta/index.json | 本地词表或固定精选资源 |
| i.imgur.com | 示例图片 | 示例本地化或删除 |
| translate-pa.googleapis.com | translateHtml | 按保留的直连翻译服务判断，不能混作原站运营请求 |

前五项是原厂依赖，包含配置、内容目录、资源和探活；不能统称为遥测。B 版已对遥测 sink 做补丁，默认配置残留 `telemetry:true` 字段也不能独立证明仍在上报。

原配置的复杂度来自基础配置、缓存 builtin、版本条件、AB 条件、地区/会员条件和用户覆盖多层合并。仅删除本地 default_config 中的开关，旧缓存或后续覆盖仍能改变结果。

推荐做法：

1. 保留现有网站解析/字幕规则的固定快照；不再接受原站 builtin 更新。
2. 服务、功能和资源采用本地白名单；删除运营标签、AB、会员排序和已不存在能力的覆盖规则。
3. 最终 policy 在所有迁移与用户设置合并后执行。旧配置不能恢复球、原厂服务或外链。
4. 包内 UI 资源从本地取；选定专家提示词和术语数据带版本保存。
5. 网络检查按“官方域名/业务路由为零；保留翻译服务和用户地址正常工作”验收。

规则热更新删除后，网站适配修复随 Owen 版本发布。这是独立维护的具体成本，不能同时承诺自动继承原站修复。

## 6. 已删功能的残留、权限与包体

| 项目 | 建议 | 边界 |
|---|---|---|
| 图片/漫画请求改写规则 | 直接删 23 条 | 32 条总数中的 301–314（无306）、317–326；315/316 为本机模型端口，另行决定 |
| `httpstat.us/429` 诊断规则 | 随旧诊断删除 | 通用 429 错误处理保留 |
| DeepL/Transmart/Volcengine/Youdao 请求头规则 | 随服务清单决定 | 保留的直连服务需验证实际需求 |
| 旧扩展 ID 的 initiatorDomains | 清除或重建 | 当前静态表限定三个原扩展 ID；保留的规则应匹配当前安装身份 |
| webRequest 权限 | MV3 版可裁剪 | 当前后台事件注册受 manifest_version===2 保护；同步移除旧 MV2 分支 |
| declarativeNetRequestFeedback | 列为移除候选 | 未见调试监听；移除后用保留服务验证 |
| 其余 DNR 权限/规则表 | 按保留请求头规则裁剪 | 不能与图片规则一起无差别删除 |
| 大量 translateWithX 快捷命令 | 简化 | 保留当前服务翻译、输入框、侧栏、字幕等实际动作 |
| `<all_urls>`、all_frames | 保留当前架构所需范围 | 网页自动注入、iframe 和任意自定义服务仍依赖它们；缩成 activeTab 属于另一项架构改变 |
| offscreen、WASM CSP | 保留 | 本地 AIFW/共享后台能力仍在；不能按“原厂残留”直接删 |
| 22 组 locale 与重复帮助文案 | 改为中文与英文回退 | 删除文件前检查动态键和 fallback；不承诺按比例节省包体 |
| 隐藏文件/图片/写作/教程/社区定义 | 第二阶段做可达性裁剪 | 已隐藏组件与仍展示入口分开统计；共享导入不整包硬删 |
| 原 PDF/preview 专属规则 | 精确删无用例外项 | 800 条规则大部分服务网站解析，不做域名字符串一刀切 |
| 原内部命名/DOM id | 低优先级 | 无用户行为收益；重命名会增加补丁维护成本 |
| 来源记录、必要 notices | 本地独立保留 | 可从主界面移出，不随推广页整份删除 |

包体的主要收益来自可达性和重复资源裁剪；改品牌文字、删 URL 常量和隐藏按钮几乎不改变架构复杂度。当前对象是编译后 bundle，最稳的第一步是修改构建补丁、裁剪根入口与对应资源，再让压缩器清理可证明不可达的代码。对共享模块按名称硬删会影响网页、字幕和本地设置。

## 8. 实施顺序与交付验收

**第一批：可见入口与全站球。** 替换文本翻译与放大外跳，统一设置，删除会员/原站品牌链接、字幕链接墙和赞助文案；硬关并删除球，保留 Nj 与播放器按钮。此批不触动翻译服务协议。

**第二批：身份与原厂网络。** 确定 Direct/BYOK 白名单，迁移旧服务选择；术语改 local-only；删除云配置、Google Drive、官方 AI 分句/ASR/语言检测、专家市场、远程配置与资源；最后删除账号 PKCE/bridge/token/UI 及商业错误映射。

**第三批：结构与包体。** 清理死代码、重复示意图、语言包、DNR、旧快捷命令和不用的权限。构建报告列出删除文件、缩减字节和残留域名，避免只靠视觉验收。

验收必须覆盖：

- 新安装无账号启动；popup/设置/侧栏/播放器不出现原站外跳与全站球。
- 主“文本翻译”进入本地功能；三个设置入口一致；Magpie 配置有唯一位置。
- 网页、iframe、选词、悬停、输入框仍按保留范围工作；关闭球后页面设置弹窗正常。
- YouTube 已有字幕：Magpie 成功、失败回退、关闭时本地分句；切视频丢弃旧请求；字幕下载正常。
- Direct/BYOK 正常；无效 Key 的 401、429、超时、取消和扩展上下文失效仍能解释并恢复。
- 本地术语增删改、CSV、历史、刷新恢复、旧 dirty 状态迁移正常；不再要求登录或重试云上传。
- 本地设置与词表导入导出正常；升级保留 Key、词条、快捷键和 Magpie 地址；旧 Pro 服务有确定迁移结果。
- 新安装及旧配置升级均检查官方域名、URL 模板、业务路由与事件处理器；实际网络无原厂请求。检查动作包括打开所有保留设置页、翻译、字幕、本地术语和错误场景。

保留通用错误系统：AI 批处理格式、服务未配置、HTTP 401/403/429/5xx、fetch、timeout、cancel、context invalidated。删除的是“去登录/升级/续费/买额度”的商业分支，不是错误传播与重试机制。
