## 服务目录

| 类型 | 核心模板 |
|---|---|
| 传统翻译 | Bing、Google、DeepLX、DeepL |
| AI 与本地服务 | Magpie、OpenAI、Claude、Gemini、DeepSeek、OpenRouter、Ollama、通用 OpenAI 兼容接口 |

DeepLX 目录入口解除原版 beta 显示限制。Magpie 模板继续预填本机地址，服务添加后沿用现有模型、密钥和提示词配置。

服务适配器与继承元数据继续保存在包内，供旧配置恢复使用；界面仅展示核心目录和用户已配置服务。配置迁移对隐藏模板添加目录标记；发现对应的用户配置或正在使用的服务时恢复其可见性。

## 实现

沿用确定性 AST 补丁，从 `upstream/` 生成，生成目录不承担源文件职责。弹窗移除旧模式状态钩子与全局更多抽屉挂载；保留局部详细设置。设置页使用两列 grid 与 sticky 目录，正文列采用 `minmax(0, 1fr)`，消除 1200 像素断点导致的横向导航回退。

划词翻译优先保留卡片内明确选择的服务；未单独指定时优先继承当前 AI 翻译服务，避免服务目录排序改变实际调用对象。

界面样式与内容保留原有朱批配色和字体系。字幕设置、分句算法与字幕导出保持既有行为。
