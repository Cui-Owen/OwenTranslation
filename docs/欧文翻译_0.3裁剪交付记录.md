## 配置与数据迁移

最终配置策略在后台、网页、弹窗、侧栏和设置的所有配置合并后执行。旧缓存、导入配置及版本覆盖不能恢复悬浮球、会员服务或远程配置。

- 原会员主翻译服务迁移为 Bing；输入、鼠标和字幕等分项服务改为继承。嵌套的网站专属设置及 `userTranslationServices` 同步清理。
- 用户 API Key、自定义服务地址、模型、提示词、Magpie 地址、快捷键和本地词条保留。自定义服务名称包含 `pro` 不触发误删。
- 本地术语保留 CAS/hash 冲突检测、串行锁、本地历史和恢复；旧云同步意图不再阻塞编辑，也不触发云写入。
- 原账号存储记录不再读取或发送。站点解析规则固定为包内快照，后续修复通过本项目构建发布。

## 保留的数据路径

| 数据 | 去向 |
|---|---|
| 待翻译网页、输入、侧栏及字幕文字 | 当前选择的直连翻译服务或用户自定义 API |
| Magpie 字幕分句 | Magpie 设置指定的地址；默认 `http://127.0.0.1:3425/v1` |
| 设置、API Key、本地术语、历史和缓存 | 扩展本地存储；本地导出由用户触发 |
| 语言检测 | 现有本地检测及回退逻辑 |
| AIFW 脱敏 | 保留包内运行时和 WASM |

内部函数名、消息命名及部分共用错误定义沿用编译包结构。裁剪依据是入口、调用链、配置合并和网络行为；没有对原版字符串做全局替换。
