# 欧文翻译工程说明

版本由 `package.json` 管理，构建时写入扩展清单。当前显示名称为「欧文翻译 v1」，内部版本为 `1.0.0`。

`npm run build` 从构建基线生成翻译引擎与页面资源，执行 TypeScript 类型检查，再通过 Vite 构建弹窗、设置页和文本侧栏。品牌文案在生成文件清单及哈希前统一处理。

`npm test` 检查 JavaScript 语法、清单资源引用、界面依赖与三语文案、配置策略、本地术语、字幕分句、划词和发布文件哈希。

`npm run package` 校验构建清单，生成 ZIP，再逐文件检查压缩包内容，输出 SHA256 校验文件与发布报告。

翻译请求使用用户选择的服务配置。本地规则、术语与字幕分句边界缓存由扩展管理。配置键和通信协议保持稳定，以兼容已有设置。
