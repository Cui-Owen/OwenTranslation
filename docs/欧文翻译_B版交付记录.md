### 防止配置重新打开

原包存在 `.add_v` 等版本覆盖及远程配置合并。仅修改默认 JSON 会在刷新后失效。因此在 background、options、popup、side-panel 和 content 五个 bundle 的最终配置返回处加入 `owenEnforceConfig`：强制停用已删模块，清除对应版本覆盖项，并处理既有用户配置。规则覆盖仍保留正文翻译、字幕和智能上下文的其余字段。

正常网页规则中的 `ad` 选择器用于排除页面广告，不属于扩展推广，保留。账号鉴权和配额判断也保留，不修改账号或会员状态。

### OCR 与 AIFW 的边界

`aifw` 不是 AI 写作。它在发送翻译请求前替换敏感文字，随后按 metadata 还原。它与 OCR 共用 offscreen 页面，所以只删除 OCR 专用能力，保留 offscreen 路由和 AIFW 文件。AIFW、字幕注入脚本和三个 Magpie 适配器均与本轮基线逐字节核对。

## Magpie 接入机制

字幕原始事件进入本地适配器后拆成保留原文和毫秒时间戳的词元。模型只返回末尾词元索引 `ends`。客户端校验覆盖范围、边界单调性和最终结束位置，再由原词元生成字幕项；模型不能改写字幕原文或虚构时间轴。

扩展后台请求本机 OpenAI 兼容接口，缓存以设置、语言及输入等信息区分；页面、视频或设置变化会取消旧任务，陈旧响应不能覆盖新字幕。失败时回落基础分句。字幕显示、后续翻译与下载沿用原管线。

本地开关打开时，本地分句优先于原官方 AI 分句，不依赖会员状态。关闭本地开关后，原有服务模式继续按原配置运行。译文生成服务在翻译设置中单独选择。
