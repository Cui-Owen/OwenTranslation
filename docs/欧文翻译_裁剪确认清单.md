# 欧文翻译：裁剪确认清单

已完成改名、黑色像素图标替换及独立 Edge 加载验证。当前仍是完整功能品牌版，以下功能尚未删除。原安装和上一版 Magpie 包均保留。

推荐保留网页、选区、悬停、输入框、侧栏文本翻译、视频双语字幕、Magpie 智能分句、自定义 API、术语、AI 翻译提示词及智能上下文。首轮去掉运营推广、文件翻译和 AI 写作；图片/漫画翻译单独选择。

## 图片翻译：需要你选择

| 选项 | 结果 | 可删除资源 |

## 修改后的验收门槛

- 网页双语、仅译文、恢复原文、滚动增量翻译，以及含 iframe 的页面。

- YouTube 原始字幕捕获、Magpie 分句、字幕翻译、边界更新和字幕下载。
- 脱敏请求替换与响应还原；选择 A 时同时检查图片及 canvas 漫画。

- 页面与扩展后台均不发起消息中心、奖励、促销、评分诱导和运营上报请求；刷新配置后也不恢复。
