# 欧文翻译 v1

基于 Edge 沉浸式翻译 1.34.3 安装包修改，保留文字翻译、视频双语字幕和 AI 智能分句，0.3 版移除原版账号、运营入口和官方云依赖。Phase 1 移除 AIFW、Offscreen、废弃资源与未使用的内嵌 CSS 副本；Phase 2 统一弹窗、文本侧栏与设置页导航，收敛翻译服务目录。

## 当前版本

显示版本：**欧文翻译 v1**；扩展版本：`1.0.0`。

安装包与校验文件见 [GitHub Release](https://github.com/Cui-Owen/OwenTranslation/releases/tag/v1)。

## 构建与版本管理

需要 Node.js 22.12+ 和 Python 3。

```sh
npm ci
npm run build
npm test
npm run package
```

`upstream/` 保存构建基线，`scripts/` 保存补丁与打包工具，`ui/` 保存界面源码，`tests/` 保存回归检查。生成的 `extension/`、`outputs/`、依赖和本地工作数据不进入 Git。版本由 `package.json` 管理；发布标签为 `v1`，后续修改通过提交和版本标签追踪。

## 加载

1. 在 Edge 打开 `edge://extensions`，开启开发人员模式。
2. 选择“加载解压缩的扩展”，选择本项目 `extension` 目录。
3. 在原扩展与欧文翻译之间只启用一个，刷新需要翻译的网页。

此项目不改写 Edge 原安装目录。加载的欧文翻译拥有独立扩展 ID，原扩展设置不会自动迁移。

## Magpie 与 AI 智能分句

Magpie 是一个普通的翻译服务来源。在“翻译服务 → 添加自定义翻译服务”中选择 Magpie，即可添加一个服务。默认接口为 `http://127.0.0.1:3425/v1/chat/completions`，模型、地址和密钥在该服务的设置中修改。添加后的 Magpie 服务和 OpenAI、DeepSeek 等服务一样，可以用于网页翻译、字幕翻译、划词和输入框。

字幕分句在“视频字幕 → YouTube 专属设置”中配置：

| 选项 | 行为 |
|---|---|
| 欧文翻译双语字幕分句基础优化 | 本地规则分句，不发网络请求 |
| AI 智能分句 | 选择任一已添加的 AI 服务（Magpie、OpenAI、Claude、Gemini、自定义 AI 等），为 YouTube 自动生成的字幕分句。选择后，此项优先于基础优化 |

AI 服务只返回字幕词元的分句边界。原文字词、顺序和时间轴由扩展保留；结果通过校验后交给原字幕显示及翻译管线。请求失败或格式无效时保留本地规则分句；连续两次失败后，本次字幕不再请求。分句请求经由扩展的翻译器发送，使用该服务自身的地址、密钥和模型。边界缓存只保存索引，不保存字幕文本，按服务和模型区分，保存 7 天。

## 功能范围

| 保留 | 已删除 |
|---|---|
| 网页双语、划词、悬停、输入框、侧栏文本翻译 | 文件、PDF、EPUB、Word 及字幕文件上传翻译 |
| 播放器字幕捕获、翻译、本地 SRT/VTT 下载、AI 智能分句 | 网页图片、漫画、截图与 OCR |
| 自定义 API、AI 翻译提示词、智能上下文（自选模型生成）、术语与自动抽取 | AI 写作、AI Reply |
| 直连翻译服务、自定义 API Key、本地术语编辑及配置导入导出 | 原版登录、会员、试用、云同步、官方模型中转、云术语 |
| 工具栏弹窗、侧栏文本翻译、播放器字幕按钮 | 页面悬浮球、固定侧栏球、原站教程与购买跳转 |
| 直接发送原文到所选翻译服务 | AIFW 脱敏、Offscreen、WASM、独占 OCR/ONNX 资源和 PDF 转发桥 |

站点规则和界面语言固定为包内版本。语言检测使用本地逻辑；界面语言保留英文和简繁中文，翻译语言范围不变。原站远程配置、在线专家目录、公共术语下载和官方 ASR 已移除。翻译请求按所选直连服务或自定义 API 配置发送。

旧配置在加载时清理：官方会员服务切换为 Bing，分项翻译服务改为继承；自定义 API Key、本地术语保留。0.3 的 Magpie 专用分句设置不再使用，需要在翻译服务中重新添加 Magpie。停用的悬浮球、远程配置及 AIFW 脱敏不会被旧配置重新开启。

## 原会员功能（本地解锁）

以下功能原版要求会员，本版在各自的判断处解除，不伪装会员身份：

| 功能 | 本版行为 | 前提 |
|---|---|---|
| YouTube 直播字幕翻译 | 无 1 分钟试用限制，升级提示已隐藏 | 直播本身提供字幕 |
| 文章术语自动抽取 | 设置页与侧栏开关可用，抽取结果写入本地术语 | 选择 AI 服务，批量模式为推荐模式，服务支持列表协议，网址在匹配列表中 |
| 字幕下载 | 在页面内选择双语、译文或原文，导出 SRT 或 VTT，不打开原厂网页 | 字幕翻译已开启并已捕获字幕；未翻译条目在“译文”中保留原文 |
| 智能上下文 | 由当前所选 AI 翻译服务生成主题、术语和风格摘要，再注入原有提示词 | AI 服务开启“智能上下文”，提示词含 `{{summary_prompt}}` 或 `{{terms_prompt}}` |
| 字幕提示词 | 服务设置中显示 `subtitlePrompt` 字段 | 自定义批量模式 |
| 划词翻译 | 任一已配置的 AI 服务都可用于划词，不再限于原版标记的服务；没有 AI 服务时使用主翻译服务（如微软翻译）。服务出错时提示检查服务设置，不显示会员推销 | 设置中开启划词翻译 |

智能上下文摘要的等待上限为 12 秒或站点规则中更长的值，摘要完成前翻译会等待。超时或模型未返回有效 JSON 时，本次翻译不带摘要继续。原厂 AI 断句开关已替换为“AI 智能分句”的服务选择。

无字幕视频识别、图片与漫画、PDF、官方托管模型和云同步依赖原厂服务器，本版未提供。

## 构建与验证

```sh
npm ci
npm run build
npm test
python3 scripts/package.py
```

`npm test` 包含 `tests/test-ui.cjs`：依赖单一版本、导入白名单、三语文案完整性与发布页面结构。

`upstream/` 保存本轮裁剪前的品牌版基线。构建先从上游包提取语言清单与服务图标（`scripts/ui-data.cjs`），再对 `ui/` 做类型检查并用 Vite 构建弹窗与设置页。`scripts/` 对编译包做语法树定位和断言式补丁，重新生成 `extension/`；不依赖上一次构建结果。构建对不匹配的函数、重复定位、重叠修改和语法错误直接失败。组合补丁后由 `scripts/shrink.cjs` 再做一轮 AST 裁剪，清除 AIFW 调用链及营销图片；最终使用保守的无引用代码清理，不重新混淆函数名。

界面按“朱批”品牌画板实现，构建时由以下补丁生成：

| 范围 | 文件 | 内容 |
|---|---|---|
| 图标 | `scripts/patch-icons.cjs` | 上下错位的两半圆环；工具栏未翻译为灰、已翻译（`badge-icons/`）为朱色，`dark-*` 用于深色主题；扩展管理页与内嵌标志用墨底应用图标 `icons/app-*.png` |
| 弹窗、设置页与文本侧栏 | `ui/`（见 [ui/README.md](ui/README.md)） | 0.4 起由源码构建：React + shadcn/ui（radix-ui）+ Tailwind，替换原版界面 |
| 侧栏引擎 | `scripts/patch-sidepanel.cjs` | 原 `side-panel.js` 保留为翻译与术语引擎，控制器改为向新界面发布状态，不再渲染 |
| 网页内 | `scripts/patch-inpage.cjs`、`scripts/ui/inpage-*.css` | 段落译文沿用沉浸式翻译原版样式，继承网页字体与字号，无朱点标记；加载占位条；划词卡片；播放器字幕菜单 |
| 分句与 Magpie | `scripts/patch-segment.cjs`、`scripts/segment/` | Magpie 服务模板与图标；内容脚本分句适配器与后台边界缓存（分句服务在新设置页“视频字幕”中选择） |
| 配色 | `scripts/patch-brand.cjs` | 侧栏与网页内脚本中内嵌的原粉色改为朱色 |

真实 Edge 回归使用独立临时配置及本机模拟 API，不修改个人浏览器配置：

```sh
NODE_PATH=/Users/owenmac/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules node tests/test-browser.cjs extension
```

## 0.4 弹窗、设置页与文本侧栏重造

加载目录仍为 `extension/`，交付包为 `outputs/欧文翻译 v1.zip`。

工具栏弹窗、设置页与文本侧栏按使用流程重新设计，三页共用同一套组件与设计语言。原版 `popup.js`（1.6 MB）、`options.js`（3.6 MB）及其样式表不再打包，扩展总体积从 15.4 MB 降至约 10 MB。侧栏的 `side-panel.js` 保留为引擎（翻译器、消息通道、文章术语绑定），只替换界面。翻译引擎与网页内界面不变。

| 页面 | 结构 |
|---|---|
| 弹窗 | 页面状态与“翻译此页 / 显示原文”主按钮；原文 → 目标语言；翻译服务；双语 / 仅译文；此网站“按默认 / 总是翻译 / 从不翻译”；视频字幕、悬停（含触发键）、划词、输入框四项开关；侧栏与设置入口 |
| 设置 · 翻译 | 常规（目标语言、默认服务、显示方式、界面语言、译文样式实时预览）；翻译服务（各场景服务分配、我的服务、添加 10 种模板、密钥/模型/接口编辑、连接测试、拉取模型列表）；网页翻译（网站与语言规则、翻译范围、排版）；术语库（AI 术语开关、抽取网站、术语库编辑与 CSV 导入导出） |
| 设置 · 随手翻译 | 划词、悬停、输入框、视频字幕（含 YouTube 分句与 AI 智能分句服务、字幕样式实时预览） |
| 设置 · 其他 | 快捷键（浏览器快捷键与网页快捷键录制）、导入与导出（含术语库、历史版本恢复、重置）、关于（启用开关、本地缓存） |
| 文本侧栏 | 原文 → 多目标语言（自动检测、互换）、多服务对比、专业模式术语库、智能换行；结果可朗读、复制、重试并标出命中术语；网页打开“文章术语”时切换为术语总览 / 详情（定位原文、修改译法）/ 添加至术语库，可随时返回文本翻译 |

界面语言提供简体、繁体与英文三套完整文案。配置写入键与原版一致，已有设置、服务与密钥直接沿用；原设置页链接（如 `#advanced`、`#services/<id>`）继续有效。

## Phase 2 界面去冗与统一

Phase 2 交付包为 `outputs/欧文翻译-0.3-Phase2.zip`（其中弹窗与设置页已由 0.4 重造取代）。详细变更与验收见 [Phase 2 交付记录](docs/欧文翻译_0.3_Phase2界面去冗与统一.md)。Phase 1 ZIP 保留为历史版本。

新建服务仅提供 Bing、Google、DeepLX、Magpie、OpenAI、Claude、Gemini、DeepSeek、OpenRouter、Ollama、通用 OpenAI 兼容接口、DeepL 共 12 个模板。未配置的旧模板不再进入服务列表与选择器；已配置服务、密钥和继承适配器继续保留。
